# 《念念》——记忆透明的 AI 陪伴助理 · 求职作品集案例

> 应聘目标：AI 产品设计（J12748 · 校招）· 本案例用于补齐"C 端 AI 对话体验设计"短板
> 完成日期：2026-10-26 · 全部数据为演示数据，非真实用户信息

## 一句话

把豆包/ChatGPT 式"有记忆的 AI 助理"做到 L1 对齐，再用两个真实项目的内核——**风云汇的验证纪律**（证据可点、口径角标、人工复核、空态不冒充）+ **森森的记忆架构**（分层记忆模块、时间衰减、偏好主动关怀）——注入成"记忆看得见、查得到、管得住"的差异化体验。

## 面试快答（详见 02 §7）

- **与 ChatGPT 记忆管理的本质区别？** 它给"条目级删除权"，我做"过程级参与权"——形成前可复核、形成后可回查、冲突时可裁决、离开时可带走。
- **数据哪来？** 作品集阶段为演示数据（逐处标注）；真实数据管线方案 = 森森架构的 draft→复核→长期库→衰减→冲突检测 映射（PRD §4）。
