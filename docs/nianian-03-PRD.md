## 1. 产品概述

- **定位**：记忆看得见、查得到、管得住的 AI 陪伴助理（详见产品方案 §1）
- **目标用户**：被"AI 失忆/记错/失控感"困扰过的 C 端 AI 陪伴/助理用户
- **本期（V1 原型）目标**：跑通"知情→积累→纠偏→回查→约束→带走"的信任主轴，每一环可演示、可验收
- **不做清单**（理由见拆解报告 §4）：语音对话与音色、角色卡/虚拟形象、星念类游戏化、订阅商业化、多角色/群聊

## 2. 全局规范（五条强约束，逐页可验收）

### G1 三端导航
断点：PC 侧栏 ≥1024 / 图标栏 768–1023 / 移动 tabbar <768。导航由 `proto.js` 的 `NAV_CONFIG` 统一下发（模块开关/排序/角标），页面只写内容不写导航；未启用模块不渲染。验收：任一页三档宽度下导航项一致且当前页高亮。

### G2 空态纪律
缺数据 = 空态卡（原因 + 补数据指引），禁止 0/空串/编造占位。验收：原型中至少两处示范空态（M4"约定承诺"模块、M2 无记忆态），空态卡文案必含"为什么空 + 怎么补"。

### G3 口径角标
任何记忆数字/状态旁必有 ⓘ，悬停（移动端点按）展示口径阶梯。置信度只有三档：**已确认**（用户采纳过）/ **未确认**（AI 刚提炼）/ **已褪色**（距上次确认 ≥30 天）。褪色展示统一文案"距上次确认 N 天"，不展示裸分数。演示数据一律角标"演示数据"。

### G4 证据可点
凡 AI 引用记忆处带 `[来源]` 角标 → 引文卡：原对话摘录（≤80字）+ 日期 + 置信度档 + 跳转详情。没有来源的记忆召回不允许出现（宁可说"我不记得"）。

### G5 视觉 token 表
暖夜主题（参数化"深色终端"契约，改值不改名）：三层次暖深底（页面/卡片/侧栏）+ 暖杏品牌色 + **金色仅用于记忆置信度与差异化数字（带辉光）** + 语义色只用于记忆状态（确认绿/未确认琥珀/冲突红/褪色灰蓝）+ 数字等宽字体。涨跌色不适用（无行情）。全站色值只存在于 `proto.css :root`。

## 4. 非功能需求

| 类 | 要求 |
|---|---|
| 性能 | 记忆面板首屏 <1s；引文卡预加载（点开零等待）；原型静态页 1440/390 双端无横向溢出 |
| 合规 | 授权前置（M1 未同意零写入）；来源文本仅存"必要摘录"非全量对话；导出/删除承诺可验证 |
| 工程 | 记忆管线映射森森架构：draft→复核→长期库→衰减打分→冲突检测；原型数据全部标注"演示数据" |
| 兼容 | 三端导航（G1）；触控目标 ≥44px；语义色不作为唯一区分（附图标） |

| 参与 | `chat_topic_click`（推荐话题点击，带记忆关联与否）· `memory_panel_visit` |
| 信任 | `memory_source_open`（来源卡打开率）· `review_decide`（复核处置时长与结果分布）· `conflict_resolve` |
| 传播 | `memory_export_done`（主权使用） |
| 护栏 | `care_marked_disturb`（打扰标记率）· `memory_delete_all` · `care_paused`（关怀关停率=负向健康指标） |

北极星：**带来源的召回占比** 与 **记忆复核完成率**（而不是对话量——信任产品先看信任）。

## 6. 边界与不做清单

| 不做 | 理由 |
|---|---|
| 语音/音色、虚拟形象 | 与"可信助理"定位冲突，Pi 已验证无形象路线；工程量另计 |
| 星念/抽卡/交易 | 游戏化与透明叙事互斥；拆解报告示其转化弱 |
| 订阅付费墙 | V1 留白；先验证信任假设 |
| 记忆跨产品共享/广告变现 | 直接违背 M1 承诺，永久红线 |
